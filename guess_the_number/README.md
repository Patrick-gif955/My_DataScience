# Guess the Number

My first real Python project.

I started with the usual "Hello World", then moved on to something with actual logic. This is a simple number guessing game.

## How it works
The computer picks a random number between 1 and 20.  
You try to guess it.

- If you guess correctly → it celebrates and the game ends.
- If your guess is too high or too low → it tells you.
- Press `d` or `D` anytime to quit.

## What I used
- `if` / `elif` / `else`
- loops (`while True`)
- user input
- basic operators and conditions
- exception handling (`try` / `except`) for invalid input

100% Python. No extra libraries except the built-in `random`.

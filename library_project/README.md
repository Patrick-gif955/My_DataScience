# Library Project

I created this basic library system with some of the core functionalities every library needs:

* Displaying books
* Borrowing books
* Returning books

For this project, I used **Object-Oriented Programming (OOP) in Python**.

## Code Explanation

I created two classes:

### Book Class

The `Book` class contains the title and author of each book. Its purpose is to store the basic details of a book so they can easily be accessed and added to the library.

### Library Class

The `Library` class is the core of the library system. It contains the methods responsible for managing the books in the library.

It has:

* `add_books()` for adding books to the library
* `show_book()` for displaying the books in the library
* `borrow_book()` for borrowing books
* `return_book()` for returning books

## Challenges

One of my biggest challenges was creating the `borrow_book()` method. At first, I simply didn't know what to do there.

The challenging part was that most of the tutorials and code examples I came across didn't address it in a way that I could easily understand. The solutions often looked more complex than what I was trying to achieve.

I had to take a step back, understand the basic architecture of how borrowing a book should work, and then come up with my own solution. I believe the approach I came up with is quite straightforward and easy to understand.

## What I Learned

Through this project, I developed a stronger understanding of **Object-Oriented Programming in Python**;I worked with classes, list and list manipulations.

It also helped me improve my problem-solving skills because I had to think through the logic of how a library should work and come up with my own solution instead of simply following a tutorial.
